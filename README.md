# Veda Internship – Task 7: Basic Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript as part of my VEDA Technology Web Development Internship – Task 7.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear and equals functionality
- Divide-by-zero handling
- Responsive calculator interface
- JavaScript event handling and DOM manipulation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

basic-calculator/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to perform calculations.

## Learning Outcome

This project helped me improve my skills in JavaScript event handling, arithmetic operations, DOM manipulation, and CSS Grid layout.
